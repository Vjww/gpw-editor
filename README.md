# GPW Edit

A Windows game editor and compatibility utility for **MicroProse Grand Prix World**, released in 1999 and based on the 1998 Formula One season.

GPW Edit is designed for players and modders who want to customise Grand Prix World, edit game data, and run the game on modern Windows systems through an easy-to-use graphical interface.

> [!IMPORTANT]
> GPW Edit is a community project and is not affiliated with or endorsed by MicroProse.

## Features

- ⚙️ **Game Setup** – Upgrade and prepare your Grand Prix World installation.
- 🏎️ **Modern Windows Support** – Apply compatibility fixes.
- 👨‍🚀 **Drivers** – Manage driver details and attributes.
- 🏁 **Teams** – Manage teams and their settings.
- 👥 **Personnel** – Manage team personnel.
- 💰 **Sponsors** – Manage sponsors and contracts.
- 🌍 **Tracks** – Manage circuits and their settings.
- 📅 **Game Year** – Set the season year.
- 💾 **Save Games** – Edit save games.
- 🌐 **Language Files** – Modify in-game text and translations.

## Requirements

- Windows 10 or 11
- .NET Framework 4.8.1
- MicroProse Grand Prix World

## Installation

### Download and Install

1. Download the latest package from the [GPW Edit releases page](https://github.com/Vjww/gpw-editor/releases/latest).
2. Extract the ZIP file to a temporary folder.
3. Run `setup.exe` to install GPW Edit.

## Usage

1. Start GPW Edit.
2. Select your Grand Prix World installation folder.
3. Upgrade the game installation.
4. Choose the area you want to edit.
5. Make and save your changes.
6. Launch Grand Prix World and enjoy!

> [!CAUTION]
> Back up your Grand Prix World installation and saved games before making changes. GPW Edit modifies game files, so keeping an untouched backup is strongly recommended.
